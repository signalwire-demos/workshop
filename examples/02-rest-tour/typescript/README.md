```bash
npm install

# Open http://localhost:8001
```

Same UI flow as the Python REST tour. 4 buttons exercise `client.phoneNumbers.list`, `client.compat.messages.create`, `client.compat.calls.list`, and `client.phoneNumbers(sid).update`.
