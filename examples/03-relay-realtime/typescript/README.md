# Pillar 3 — RELAY Realtime (TypeScript)

## Run

```bash
npm install
npm start
# Open http://localhost:8002
```

Mirror of the Python RELAY example: backend opens a `RelayClient` connection in the background, forwards events over a browser WebSocket, and has an outbound dial button.
